# TrevUI

Open source Vue 3 UI library on Reka UI. A CLI copies components, blocks,
layouts and themes into your project as source you own.

Work in progress. See [docs/spec.md](docs/spec.md) for scope and
[tasks/README.md](tasks/README.md) for the build plan.

## Develop

Requires Node 22 and pnpm.

```sh
pnpm install
pnpm test
pnpm typecheck
```
