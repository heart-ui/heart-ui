# P2-09 Progress

## Why

**Request (verbatim):** Start P2-09 (progress component) in cuti/task-1 via sdlc

Task [P2-09](../../../tasks/phase-2.md#tier-2-components), Recipe C: `progress`. Catalog row: built on Reka `Progress`, no parts, "`size`. Indeterminate when the value is null." The spec is [registry/ui/progress/progress.md](../../../registry/ui/progress/progress.md). Uploads, imports and long-running actions need a determinate or indeterminate progress bar that follows the theme tokens, RTL and reduced motion.

## Decisions

| Decision | Ruled out | Why |
|---|---|---|
| Props `modelValue` (`number \| null`, default `null`), `max` (`number`, default `100`), `size` (`'sm' \| 'md' \| 'lg'`, default `'md'`), `class` | Exposing `getValueLabel`, `getValueText`, `as`, `asChild`, or `update:modelValue` | Matches Reka `ProgressRoot` and Heart UI's minimal API; callers pass `aria-label`, `aria-labelledby` or `aria-valuetext` directly as fallthrough attributes, and a progress bar is read-only. |
| Pass `:get-value-label="() => undefined"` to `ProgressRoot` | Keeping Reka's default `getValueLabel` | Reka's default writes `aria-label="50%"` on determinate bars only, duplicating `aria-valuenow`, hiding missing labels from axe, and colliding with `aria-labelledby`. Callers name every bar explicitly. |
| Track heights `sm` (`h-1`), `md` (`h-2`), `lg` (`h-3`) on `rounded-full bg-muted`; fill `bg-primary` using logical `inlineSize: ${percent}%` | `h-control-*` heights; `translateX(-...)` | A progress track is thinner than an interactive control; `inline-size` grows from inline-start in both LTR and RTL without `:dir()` or `rtl:`. |
| Indeterminate uses a `w-2/5` indicator with a self-contained `@keyframes heart-progress-indeterminate` sliding `margin-inline-start` in `@layer components` under `@media (prefers-reduced-motion: no-preference)`, centered (`margin-inline: auto`) when motion is reduced | Editing shared `theme.css`; `animate-pulse` on a full bar | `heart-ui add` does not update `theme.css` in existing projects; a centered `w-2/5` static state is visibly distinct from `0%` and `100%` under reduced motion and in static visual snapshots, and `margin-inline-start` follows RTL. |
| Clamp finite `modelValue` to `[0, max]`, treat `NaN`/non-finite as `null` (indeterminate), fall back non-positive/non-finite `max` to `100` and unknown `size` to `md` | Letting Reka log `console.error` or render `NaN%` | Prevents broken layouts and console errors on transient out-of-range inputs from callers. |

## Acceptance criteria

- **AC-001** Spec, Props & Tokens: renders a `rounded-full` `bg-muted` track with a `bg-primary` indicator at `sm`, `md` (default) and `lg` heights (`sm < md < lg`), falling back to `md` for unknown runtime sizes.
- **AC-002** Spec, Props & States: determinate values (`0`, partial, `max`, custom `max`) set `aria-valuemin="0"`, `aria-valuemax`, `aria-valuenow`, `data-state` (`loading` / `complete`) and logical indicator fill width in both LTR and RTL; out-of-range values clamp to `0..max` and invalid `max` (`<= 0`, `NaN`) falls back to `100` without console errors.
- **AC-003** Spec, States: `modelValue` of `null`, omitted, or `NaN` sets `data-state="indeterminate"`, omits `aria-valuenow`, renders a visible partial bar (`w-2/5`), and animates only under `prefers-reduced-motion: no-preference`.
- **AC-004** Spec, Accessibility & Props: renders `role="progressbar"`, never emits a synthetic `aria-label` when unnamed or using `aria-labelledby`, forwards `aria-label`, `aria-labelledby`, `aria-valuetext` and other attributes to the root, and merges `class` last.
- **AC-005** Definition of done 3: axe reports no violations in the demo, light and dark.
- **AC-006** Definition of done 1, 4–6 and the docs page: the registry build includes `progress`, and the docs site builds its page and demo.

## Must never break

- Every other item, its baselines and its docs page stay as they are.
- Built CSS never uses `:lang(` (logical properties only, checked by `tests/playgrounds.test.ts`).

## Out of scope

- Circular/ring progress indicators, segmented steps (`stepper`, P3-10), and inline percentage labels (callers render text alongside the bar).
