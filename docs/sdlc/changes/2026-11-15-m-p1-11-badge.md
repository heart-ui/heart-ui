Task [P1-11](../../../tasks/phase-1.md#tier-1-components), Recipe C: `badge`. Catalog row: no primitive, no parts; "`variant`: neutral, primary, success, warning, danger, info. `size`: sm, md." The spec is [registry/ui/badge/badge.md](../../../registry/ui/badge/badge.md), committed on its own (2a5d1e8).

## Decisions

| Decision | Ruled out | Why |
|---|---|---|
| Each status variant uses its checked `-subtle` pair (`<s>-subtle` behind `<s>-subtle-foreground`), `primary` uses `primary-subtle`, `neutral` uses `muted` behind `muted-foreground` | solid status fills with `-foreground` text | Subtle pairs read as labels, not buttons, and are contrast-checked text pairs; solid fills shout in a table. |
| A `span` with `rounded-full`, `text-xs` (`sm`) or `text-sm` (`md`), a `leading` slot for an icon | `as`/`asChild` | A badge is inline text; nothing in the catalog asks for another element. |
| `size` is `sm \| md`, not the shared `sm \| md \| lg` | `lg` | The catalog row names `sm` and `md` only. |

## Acceptance criteria

- **AC-001** Spec, Props: each variant sets its subtle background and text colours; each size sets its text size and padding; `class` merges last.
- **AC-002** Spec, Slots and Accessibility: the label renders as text; the `leading` slot renders before it, `aria-hidden`.
- **AC-003** Definition of done 3: axe reports no violations in the demo (every variant at each size, with an icon, in a table and beside a heading), light and dark.
- **AC-004** Definition of done 1, 4–6 and the docs page: `pnpm check:item badge` passes and the docs site builds a `badge` page whose tables match the types.
