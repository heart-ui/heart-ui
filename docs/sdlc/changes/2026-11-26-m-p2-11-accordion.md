# P2-11 Accordion

## Why

**Request (verbatim):** continue (the next ready task after P2-10: P2-11 accordion, Recipe C in tasks/README.md)

Task [P2-11](../../../tasks/phase-2.md#tier-2-components), Recipe C: `accordion`. Catalog row: built on Reka Accordion, parts Item, Trigger, Content, "`type`: single, multiple." The spec is [registry/ui/accordion/accordion.md](../../../registry/ui/accordion/accordion.md). FAQs, settings groups and detail pages need headed sections that show and hide, keyboard-navigable and themed.

## Decisions

| Decision | Ruled out | Why |
|---|---|---|
| Root props `type` (`single` default), `collapsible` (default `true`), `disabled`, `defaultValue`, `v-model`, `class` | Reka's default `collapsible: false`; exposing `orientation`, `dir`, `unmountOnHide`, `as` | Closing the open item with a second click is what people expect from an FAQ; a vertical accordion needs no `orientation`, and arrow keys are up and down in either direction. |
| `AccordionTrigger` renders Reka's header (`h3`) and trigger together, with a `chevron-down` icon that turns 180° when open | A separate `AccordionHeader` part; a heading-level prop | The catalog names three parts; `h3` is Reka's default and the spec tells callers where it fits. |
| Height animation from a keyframe on `--reka-accordion-content-height`, in a private `@layer heart-accordion` in `AccordionContent.vue`'s `<style>`, timed by `--h-duration-normal` and `--h-ease` | An arbitrary-value class; Tailwind layer names in `<style>`; editing `theme.css` | No arbitrary values in `registry/`; conventions allow keyframes in `<style>`; the recurring defect forbids Tailwind layer names there; `heart-ui add` doesn't update `theme.css`. `--h-duration-normal` is 0 ms under reduced motion. |

## Acceptance criteria

- **AC-001** Spec, Props: by default (`single`, collapsible) a click on a trigger opens its item and closes any other, and a second click closes it; `v-model` reports the open item's `value` and opens an item set by the parent; `defaultValue` opens an item at first.
- **AC-002** Spec, Props: with `collapsible` set to `false` a click on the open item's trigger leaves it open; with `type="multiple"` several items stay open and `v-model` is an array of their values.
- **AC-003** Spec, Keyboard: `Enter` and `Space` toggle the focused item; `ArrowDown`, `ArrowUp`, `Home` and `End` move focus between triggers.
- **AC-004** Spec, Props & States: a disabled item, or every item of a disabled accordion, doesn't open on click and its trigger is disabled.
- **AC-005** Spec, Accessibility: each trigger is a button inside an `h3` with `aria-expanded` and `aria-controls`; each open content is a `region` named by its trigger.
- **AC-006** Spec, Tokens: items are divided by `border-border`, the chevron turns when open, the trigger has the focus ring, `class` merges last on every part, and the height animation sits in a private layer, never a Tailwind layer.
- **AC-007** Definition of done 3: axe reports no violations in the demo, light and dark, with items closed and open.
- **AC-008** Definition of done 1, 4–6 and the docs page: the registry build includes `accordion`, and the docs site builds its page and demo.
