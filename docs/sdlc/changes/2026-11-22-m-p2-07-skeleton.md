# P2-07 Skeleton

## Why

**Request (verbatim):** P2-07 skeleton (tasks/phase-2.md, Tier 2 components)

Task [P2-07](../../../tasks/phase-2.md#tier-2-components), Recipe C: `skeleton`. Catalog row: built on nothing, no parts, "Shape set by `class`. Respects reduced motion." The spec is [registry/ui/skeleton/skeleton.md](../../../registry/ui/skeleton/skeleton.md). The `skeleton-page` block (P2-43) and every layout's loading state need placeholders shaped like the content that is on its way.

## Decisions

| Decision | Ruled out | Why |
|---|---|---|
| One `div` with only `class`: `rounded-md bg-muted motion-safe:animate-pulse`, no size of its own | `variant` or `shape` props (text, circle); `as` | The catalog says the shape comes from `class`; a text line is `h-4 w-48`, a circle `size-control-md rounded-full`. |
| Pulse with Tailwind's `animate-pulse` under `motion-safe:` | A new keyframe token; `motion-reduce:animate-none` | `button`'s spinner uses `motion-safe:animate-spin`; under reduced motion nothing animates at all, and the theme has no pulse token. |
| `aria-hidden="true"` always | A `role="status"` or a loading label on each skeleton | A placeholder carries nothing to read; the region it fills says it is loading (`aria-busy`), once, not once per bar. |

## Acceptance criteria

- **AC-001** Spec, Tokens: by default the skeleton is a block on the `muted` surface with `radius-md` corners and no size of its own.
- **AC-002** Spec, Props: `class` sets its shape and size and merges last (`rounded-full` replaces `rounded-md`).
- **AC-003** Spec, States: it pulses when motion is allowed, and its pulse rule applies only under `prefers-reduced-motion: no-preference`.
- **AC-004** Spec, Accessibility: it has `aria-hidden="true"`, and other attributes fall through to the `div`.
- **AC-005** Definition of done 3: axe reports no violations in the demo, light and dark.
- **AC-006** Definition of done 1, 4–6 and the docs page: the registry build includes `skeleton`, and the docs site builds its page and demo.
