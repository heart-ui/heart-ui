## Why

**Request (verbatim):** "you build all planned tasks by yourself, when done i will do only 1 review round with you." (working mode in docs/questions.md, 2026-11-15).

Task [P1-10](../../../tasks/phase-1.md#tier-1-components), Recipe C: `card`. Catalog row: no primitive, parts Header, Title, Description, Content, Footer; "`variant`: default, outline." The spec is [registry/ui/card/card.md](../../../registry/ui/card/card.md), committed on its own (15ce9d0).

## Decisions

| Decision | Ruled out | Why |
|---|---|---|
| `Card` and `CardTitle` take `as` through Reka's `Primitive` (`div` and `h3` by default), as `button` does | fixed elements | A card is often a `section` or `article`, and its title's heading level depends on the page outline. |
| A component token `--h-card-radius` (falling back to `--h-radius-lg`), mapped in `theme.css` as `rounded-card` | `rounded-lg` directly | The component-layer pattern of `button`, `input` and `dialog`: a theme may round cards differently. It adds a token, as P0-10 to P0-12 did for theirs. |
| `default`: `surface-raised`, `border`, `shadow-sm`; `outline`: `surface`, `border`, no shadow | — | The spec's Tokens section; `border` is the token for card edges. |
| Parts pad with `p-6` (header, content, footer), header gap `gap-1.5`, content without top padding after a header | spacing tokens for every gap | Numeric spacing is allowed for layout inside an item; the dialog body uses `p-6`. |

## Acceptance criteria

- **AC-001** Spec, Props: `Card` renders a `div` by default or the element `as` names; `variant` sets the surface, border and shadow; `class` merges last on every part.
- **AC-002** Spec, Props and Accessibility: `CardTitle` renders an `h3` by default or the heading `as` names; a card named by its title (`aria-labelledby`) is a named region.
- **AC-003** Spec, Tokens: the corner radius follows `--h-card-radius`, falling back to `--h-radius-lg`.
- **AC-004** Definition of done 3: axe reports no violations in the demo (both variants, with and without each part), light and dark.
- **AC-005** Definition of done 1, 4–6 and the docs page: `pnpm check:item card` passes and the docs site builds a `card` page whose tables match the types.
