# P2-14 Table

## Why

**Request (verbatim):** P2-14 table component (tasks/phase-2.md, Tier 2 components, Recipe C)

Task [P2-14](../../../tasks/phase-2.md#tier-2-components), Recipe C: `table`. Catalog row: native `table`, parts Header, Body, Row, Head, Cell, Caption, "`size` sets row density. Scrolls inside its own container." The spec is [registry/ui/table/table.md](../../../registry/ui/table/table.md). List layouts and the Phase 3 `data-table` need a themed, accessible table.

## Decisions

| Decision | Ruled out | Why |
|---|---|---|
| `Table` renders a scroll container `div` around the `table`; `class` and attributes go on the `div` | Attributes on the `table` (shadcn-vue) | The root element takes fallthrough attributes (conventions); a height set on the container then scrolls the rows. The table is named by its caption, not an attribute. |
| The container gets `tabindex="0"`, and `role="region"` named by the caption, only while the table overflows it (a `ResizeObserver` after mount) | Always focusable; never focusable | Keyboard users must reach a scrolling region (axe `scrollable-region-focusable`), but a stop on every table that fits is noise. SSR renders it unfocusable; the observer runs on the client only. |
| Row density from `size` (`sm`, `md`, `lg`, default `md`) through a provided context: each `th` and `td` is at least `h-control-<size>` tall and padded `px-control-px-<size>` | Fixed spacing; `size` on each cell | Follows the density knob like controls do; a control in a cell lines up with the row. One prop on the root, as the catalog says. |
| `TableHead` declares `scope` (`col`, `row`, `colgroup`, `rowgroup`) | `scope` as a fallthrough attribute | Row headers are the main accessibility case, and spec examples are type-checked: a non-global attribute must be a declared prop. |
| No hover, selected or footer styles | shadcn's row hover, `data-state="selected"` and `TableFooter` | Not in the catalog row; `data-table` adds what sorting and selection need. |

## Acceptance criteria

- **AC-001** Spec, Accessibility: `Table` renders a `div` holding a `table`; the parts render `thead`, `tbody`, `tr`, `th`, `td` and `caption`; the table is named by its caption; header cells in `TableHeader` are column headers, and `TableHead scope="row"` is a row header.
- **AC-002** Spec, Props (`size`): with `md` by default, each cell is as tall as `h-control-<size>` and padded inline by `control-px-<size>`; `sm` rows are shorter than `md`, and `md` shorter than `lg`.
- **AC-003** Spec, Accessibility (overflow): a table wider than its container scrolls inside it while the page does not scroll; the container then has `tabindex="0"` and is a region named by the caption (a caller's caption `id` too); a table that fits has neither, and loses them when its container grows to fit it.
- **AC-004** Spec, Keyboard: `Tab` stops on the container, with a visible focus ring, only while the table overflows; a table that fits is skipped.
- **AC-005** Spec, Tokens: the header sits on `surface-sunken` with a border under it; header cells are start-aligned, `muted-foreground` and medium weight; body rows have a border between them and none under the last; `class` merges last on every part, and `Table`'s `class` and attributes land on the container.
- **AC-006** Definition of done 3: axe reports no violations in the demo, light and dark, and at 375 px.
- **AC-007** Definition of done 1, 4–6 and the docs page: the registry build includes `table`, and the docs site builds its page and demo.

  - Dependency audit r1 → `dependency-audit-r1.md` → `VERDICT: PASS`. Two pre-existing moderates, in `glob` and `minimatch` under the `apps/playground-nuxt` build chain, are rated low.

    - CR-002 is medium: focus was lost when a focused container stopped overflowing.
    - CR-003–005 and CR-007 are low:
      - CR-003: a nested table's row heads got `scope="col"`.
      - CR-004: an uncaptioned overflowing table was an unnamed tab stop.
      - CR-005: row headers never wrapped.

    - CR-006 (two captions) is rated not a bug, since HTML allows one caption per table.
  - Code r2 (closing check) → `code-reviewer-r2.md` → `VERDICT: PASS`. CR-003, CR-005 and CR-007 held. Three bugs the fixes left open were fixed without another round, test first:
    - CR2-001 (medium): a window switch still dropped the tab stop.
    - CR2-003 (low): a caller's `aria-label` sat on a plain div when the table fit, and a caption overrode it.
    - CR2-004 (low): camelCase `ariaLabel` was missed.
  - Also from r2: the CR2-005 comment was corrected. CR2-006 (stale baselines) is not a bug: `check:item` re-ran the visual tests after each round.
- **Fixed:**

Test: `leaves a table that fits unfocusable when its rows have fractional heights`, at five fractional control heights and four row counts.   - CR-004, CR2-003 and CR2-004, one fix: a caller's `aria-label` or `aria-labelledby` (either spelling) always makes the container a region and wins over the caption. Tests: `is a region named by the caller…`, `is a region named by a aria-label/ariaLabel on a table that fits, with no axe violations`, `is named by the caller’s aria-label over its caption`.
  - CR-003: `Table` resets the header flag. Test: `gives a table nested in a header cell no column scope on its row heads`.
  - CR-005: `whitespace-nowrap` applies only to `scope="col"`. Test: `wraps row headers, and keeps column headers on one line`.
  - CR-007: the test waits for a measurement first.
